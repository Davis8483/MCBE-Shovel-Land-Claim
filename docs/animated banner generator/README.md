# Rendering
start the render\
`node render_banner.js`

ctrl + c to cancel the render before output.webm is created as this will delete the .scene_cache directory

use the pngs from .scene_cache with an [online WEBP maker](https://ezgif.com/webp-maker) to animate the logo. I attempted to use the webm output and convert that to a gif although transparency was lost.
